# TradeWorks AI Industries

Standalone industry-page bundle for TradeWorks AI.

## Included

- `industries/` industry hub and individual industry pages
- Industry CSS and required shared CSS
- Industry JS and required shared JS
- Shared header/footer components used by the pages
- Industry images and small shared brand assets required for rendering

## Local Preview

```bash
npm run serve
```

Then open `http://127.0.0.1:8000/industries/`.
