Frequently Asked Questions

Which platforms does TradeWorks AI integrate with?

ServiceTitan, Jobber, Housecall Pro, HubSpot, Salesforce, Zoho, Google Calendar, Outlook, QuickBooks, WhatsApp, Facebook Messenger, and more. Full CRM integration is included on the Professional plan ($40/mo). The Starter plan ($10/mo) includes Google Calendar.

Does data stay secure when using TradeWorks AI integrations?

Yes. All integrations use encrypted API connections. No customer data is stored on intermediary servers. Data flows directly between TradeWorks AI and your connected platforms using secure, authenticated API calls.

What if I switch CRMs?

We handle the migration for you. Our consulting team will disconnect your old CRM, connect your new platform, and migrate your data so nothing is lost. Data migration packages start at $249.

What if my platform is not listed?

Custom integrations are available via Zapier, Make, or custom API connections. If your platform has an API, we can likely connect it. Consulting for custom integrations starts at $199.

Is there an extra cost for integrations?

Standard integrations are included on the Professional plan ($40/mo) with no additional fees. The Starter plan ($10/mo) includes Google Calendar. Custom API integrations start at $199, and full CRM setup packages start at $499. View full pricing →
